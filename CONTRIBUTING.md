# Contributing to Sistema Matrícula UTP

## Estrategia de Ramas (GitHub Flow)
- La rama `main` es la rama principal y está protegida. Todos los cambios deben pasar por Pull Request (PR).
- Para desarrollar una nueva funcionalidad, crea una rama con el formato `feature/{nombre-funcionalidad}`.
- Para corregir un error, crea una rama con el formato `bugfix/{nombre-error}`.

## Responsable de Versiones
- **Integrador 1 - Grupo 6**

## Proceso de Pull Request
1. Haz un fork del repositorio.
2. Crea tu rama de características (`git checkout -b feature/AmazingFeature`).
3. Haz un commit de tus cambios (`git commit -m 'feat: Add some AmazingFeature'`). Usa Conventional Commits.
4. Haz un push a la rama (`git push origin feature/AmazingFeature`).
5. Abre un Pull Request.
